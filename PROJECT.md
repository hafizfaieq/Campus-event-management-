# Project Documentation

## Objective
Build a complete Campus Event Management System demonstrating front end, back end, database, REST APIs and GitHub collaboration.

## Team Roles
1. Team Lead / Project Manager
2. Front-End Developer 1
3. Front-End Developer 2
4. Back-End Developer 1
5. Back-End Developer 2 / Database & Testing

## Functional Requirements
Home page, event listing, event details, search, category filtering, registration, login and admin event CRUD.

## Suggested Branches
- main
- feature/frontend-ui
- feature/frontend-functionality
- feature/backend-api
- feature/database-testing

## Testing
Test UI buttons, forms, navigation, search, filters and responsive layout. Test GET/POST/PUT/DELETE APIs in Postman and verify database insert/select/update/delete.
