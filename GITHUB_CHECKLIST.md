# GitHub Submission Checklist

Create the real GitHub repository and perform these instructor-required activities:
- Add all 5 team members as collaborators.
- Create Issues for Home Page, Registration Form, REST API, Database and Integration.
- Create feature branches.
- Make at least 4 meaningful commits for each assigned development role.
- Open Pull Requests into main.
- Perform code review and merge approved PRs.
- Capture screenshots of Issues, Branches, PRs, Reviews, Commits and final application.
- Do not claim these GitHub actions are complete until they are actually performed.
